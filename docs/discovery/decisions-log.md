# PROJECT WORDPLAY: יומן החלטות

מסמך חי שמתעד את ההחלטות שהתקבלו בשלב האפיון. כל החלטה מסומנת לפי הסטטוס שלה.

- ✅ **סופי:** אושר על ידי המשתמשת.
- 🟡 **המלצה:** ממתין לאישור.
- ❓ **פתוח:** נדרש מידע נוסף.
- ❌ **בוטל:** הוחלף בהחלטה מאוחרת יותר.

---

## סבב 1: הצרכים והמטרות (✅ סופי)

| # | נושא | החלטה |
|---|------|--------|
| 1.1 | מטרה לימודית | שני יעדים במקביל: להרחיב את אוצר המילים במילים חדשות, ולחזק את הזכירה וההבנה של מילים שכבר מוכרות. |
| 1.2 | מה לא חשוב | איות, הקלדה, דקדוק תיאורטי. אין ענישה על שגיאות כתיב. |
| 1.3 | תחומי עדיפות | (א) אנגלית יומיומית: שיחות, טיולים, מסעדות, קניות, מצבים חברתיים. (ב) אנגלית עסקית: פגישות, ניהול, ייעוץ, שיווק, משא ומתן. (ג) הבנת סדרות, סרטונים ותוכן. |
| 1.4 | משך סשן | גמיש, מ-5 דקות ועד 30 דקות ויותר. אפשר לעצור בכל רגע בלי לאבד התקדמות או רצף. |
| 1.5 | חוויה | גיוון אמיתי במכניקות, בסיטואציות ובאתגרים, ולא רק בצבעים. רמת פרימיום. |
| 1.6 | היקף | משתמשת אחת כרגע. הארכיטקטורה צריכה לאפשר ריבוי משתמשים בעתיד בלי להעמיס על הגרסה הראשונה. |
| 1.7 | בנק מילים | כל המילים שנלמדו, עם רמת השליטה בכל מילה ואפשרות לחזור לכל אחת. |
| 1.8 | מבחן רמה | הערכה אובייקטיבית שאינה מבוססת על הערכה עצמית. |
| 1.9 | מנוע למידה | חזרות מרווחות, שליפה אקטיבית, התאמת קצב. |
| 1.10 | פלטפורמה עיקרית | אייפון, Mobile First, ממשק בעברית RTL ותוכן באנגלית LTR. |

## סבב 3: החלטות מהותיות (✅ סופי)

| # | נושא | החלטה |
|---|------|--------|
| 3.1 | תקציב תפעול | עד 20 דולר בחודש, ועדיף פחות. תוכן שאפשר להפיק מראש (תמונות, קריינות, סצנות) מופק פעם אחת ונשמר. AI בזמן אמת רק כשיש ערך מוכח. כל פיצ'ר בעלות נוספת מוצג עם עלות וערך לפני החלטה. |
| 3.2 | אין דיבור ואין הקלדה | האפליקציה **משמיעה** הרבה: מילים, משפטים, דיאלוגים, מוזיקה ואפקטים. היא **לא דורשת** לדבר, להקליט או להקליד. האינטראקציה היא בחירה, התאמה, גרירה, משחקי זיכרון ומשימות ויזואליות. |
| 3.3 | כנות במדידה | אסור להציג "יכולת דיבור" כאילו נבדקה. כל מדד מסומן כנמדד, כמוערך או כדיווח עצמי. |
| 3.4 | נגד שחיקה | הניסיון עם Duolingo הוביל לתחושת מיצוי ונטישה. דרישה מרכזית: גיוון שממשיך להפתיע גם אחרי חודשים. |
| 3.5 | מילים חדשות | המערכת **ממליצה** על כמות, ולא חוסמת. אפשר להמשיך ללמוד, והמערכת מציגה את ההשפעה על עומס החזרות העתידי. |
| 3.6 | העדפה עיצובית ראשונית | עולם מאויר בהשראת Paper Theatre: צבעוני, עשיר בדמויות, עם עומק שכבות. שובב ומתוחכם, לא ילדותי ולא שטוח. **לא אישור סופי.** |
| 3.7 | מטאפורת העולם | מטאפורת "העיר" פתוחה מחדש. בוחנים חלופות. |

## סבב 4: המלצות חדשות (🟡 ממתין לאישור)

| # | נושא | המלצה |
|---|------|--------|
| 4.1 | שליפה שקטה | "חשבי קודם": האפשרויות נחשפות רק אחרי שליפה פנימית. בנוסף, הרכבת המילה מהברות שמע (לא מאותיות), מסיחים קרובים במשמעות, ובחירה מתוך מאגרים גדולים. |
| 4.2 | מדד מרכזי | "מילים שאת מבינה" (נמדד) ו"מוכנות לשימוש פעיל" (הערכה, ומסומנת כך). אין מדד "דיבור". |
| 4.3 | מנגנון נגד שחיקה | 7 שכבות גיוון: מאגר מכניקות שנפתח בהדרגה, כללי רוטציה, הקשרים מתחלפים, עונות, אירועי הפתעה, משנים (remix) וסיפור מתמשך. |
| 4.4 | הפקת תוכן | ערכות סצנה מודולריות ו-3 רמות טיפול בפריט (Hero, Kit, Light). הכול מופק מראש. |
| 4.5 | מטאפורה מומלצת | "התיאטרון הנודד": להקת תיאטרון בסיבוב הופעות, במה-דיורמה שמתמלאת במילים, וצבע שמשקף את חוזק הזיכרון. "תיקי חקירה" כמצב אירוע מתחלף. |
| 4.6 | כיוון ויזואלי מומלץ | Pop-up Theatre (נייר חתוך בשכבות). ייבחר סופית אחרי שתהיינה המחשות. |
