# PROJECT WORDPLAY: יומן החלטות

מסמך חי שמתעד את ההחלטות שהתקבלו בשלב האפיון. כל החלטה מסומנת לפי הסטטוס שלה.

- ✅ **סופי:** אושר על ידי המשתמשת.
- 🟡 **המלצה:** ממתין לאישור.
- ❓ **פתוח:** נדרש מידע נוסף.

---

## סבב 1: הצרכים והמטרות (✅ סופי)

| # | נושא | החלטה |
|---|------|--------|
| 1.1 | מטרה לימודית | שני יעדים במקביל: להרחיב את אוצר המילים במילים חדשות, ולחזק את השליפה והשימוש במילים שכבר מוכרות. |
| 1.2 | מה לא חשוב | איות, הקלדה, דקדוק תיאורטי. אין ענישה על שגיאות כתיב. |
| 1.3 | תחומי עדיפות | (א) אנגלית יומיומית: שיחות, טיולים, מסעדות, קניות, מצבים חברתיים. (ב) אנגלית עסקית: פגישות, ניהול, ייעוץ, שיווק, משא ומתן. (ג) הבנת סדרות, סרטונים ותוכן. |
| 1.4 | משך סשן | גמיש, מ-5 דקות ועד 30 דקות ויותר. אפשר לעצור בכל רגע בלי לאבד התקדמות או רצף. |
| 1.5 | חוויה | גיוון גבוה: משחקים, סיטואציות ויזואליות, אנימציה, האזנה, דיבור ואתגרים מתחלפים. רמת פרימיום. |
| 1.6 | היקף | משתמשת אחת כרגע. הארכיטקטורה צריכה לאפשר ריבוי משתמשים בעתיד בלי להעמיס על הגרסה הראשונה. |
| 1.7 | בנק מילים | כל המילים שנלמדו, עם רמת השליטה בכל מילה ואפשרות לחזור לכל אחת. |
| 1.8 | מבחן רמה | הערכה אובייקטיבית שאינה מבוססת על הערכה עצמית. |
| 1.9 | מנוע למידה | חזרות מרווחות, שליפה אקטיבית, התאמת קצב. |
| 1.10 | פלטפורמה עיקרית | אייפון, Mobile First, ממשק בעברית RTL ותוכן באנגלית LTR. |

## סבב 2: המלצות על מנגנונים, משחקיות, מסכים ושפה ויזואלית (🟡 ממתין לאישור)

| # | נושא | המלצה |
|---|------|--------|
| 2.1 | יחידת למידה | "פריט לשוני": מילה, צירוף שגור, phrasal verb או collocation, כולל משמעות ספציפית. לא מילה בודדת בלבד. |
| 2.2 | מודל ידע | 4 מסלולי שליטה נפרדים לכל פריט: זיהוי, שמיעה, שליפה, שימוש. ל-7 המצבים מהבריף יש מקבילה במסלולים האלה. |
| 2.3 | אלגוריתם חזרות | תזמון לפי מודל זיכרון מודרני (משפחת FSRS), נפרד לכל מסלול. |
| 2.4 | קליטת מילים חדשות | מספר המילים החדשות נקבע לפי עומס החזרות, כדי למנוע "חוב חזרות". |
| 2.5 | בדיקת תשובות | בעיקר בקול. בודקים משמעות ולא איות. כשהזיהוי לא בטוח, עוברים להערכה עצמית. |
| 2.6 | מבנה סשן | סשן בנוי מ"סבבים" קצרים של 2-3 דקות. אפשר לעצור אחרי כל סבב. |
| 2.7 | רצף | "קצב שבועי" ולא רצף יומי נוקשה. |
| 2.8 | מטאפורת התקדמות | "העיר": שכונות לפי תחום, מקומות לפי סיטואציה, וחלונות מוארים לפי חוזק הזיכרון. |
| 2.9 | תגמול | מתגמלים זכירה מוכחת אחרי פער זמן, לא כמות ולא מהירות. |
| 2.10 | ויזואליה | כל סוג פריט מקבל טיפול חזותי שמתאים לו. מילים מופשטות מקבלות סצנה או ניגוד ולא תמונה בודדת. |

## ❓ שאלות פתוחות

- תקציב תפעול חודשי.
- איזה חלק מזמן השימוש מאפשר לדבר בקול.
- ניסיון קודם עם אפליקציות לימוד ומה גרם לנטישה.
- כיוון ויזואלי מועדף (ייבחר אחרי שתהיינה המחשות).
